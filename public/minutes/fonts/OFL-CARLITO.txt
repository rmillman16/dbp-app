Carlito fonts — bundled with this app for PDF export.
Source: https://github.com/googlefonts/carlito

These files are a pre-subsetted build (fonttools/pyftsubset): trimmed to the
Latin + Latin-1 + Latin Extended-A character set plus common punctuation
(everything realistic for English/European meeting notes), with hinting
instructions and unused OpenType layout tables stripped. This is a static,
offline optimization for file size only — it does not change the license.
